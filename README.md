# NeuraLLM

Create NeuroLLM 2.0 as a new, clean research software project that answers one falsifiable question:

Can a simulated neural controller regulate LLM decoding more effectively than a strong fixed sampler, bounded random perturbation, and a competent non-neural adaptive controller under matched model, prompt, seed, and generation-budget conditions?

The project must produce a valid result even when the answer is no. Engineering completion must not depend on obtaining a positive scientific result.
